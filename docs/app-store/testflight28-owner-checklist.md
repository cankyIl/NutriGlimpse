# NutriGlimpse 1.0 (28) - iPhone acceptance checklist

Use this checklist after TestFlight lists version 1.0 (28) as available. Install it as an update over the existing app so we can check that saved data survives. Do not uninstall first. TestFlight availability does not mean the app has been published in the App Store.

1. Open the updated app. Confirm your saved My Needs choices and preferences remain. Change one harmless preference, save, close and reopen. Save should return to the main screen, including when the numeric keyboard was open.
2. At home, photograph a clearly labeled package. Confirm the product, food facts, rating and suitable alternatives appear; check that product images and store names are useful. Missing aisle information should remain absent rather than invented. Note the approximate time and any exact error text.
3. Try Shelf Camera with several different packages, including more than nine, then Finish with a partial final group. Captured, checked and distinct counts should progress, and valid results should appear. Check duplicates and alternatives where appropriate.
4. Check permission refusal, retry after reconnecting, and leaving/returning while a scan runs. At a store, check the selected-store label; at home with no selected store, check nearby-store suggestions.
5. Open Privacy & storage. Check support/privacy links and health-sharing choices. Do not reset your real saved data just to test deletion. Use a separate disposable profile/device for reset and encrypted backup/restore tests.

Please report device model, iOS version, build 28, approximate scan time and the exact screen message for a failure. Avoid sending a full medical report or private credentials. Simulator checks already cover setup/save/persistence and initial iPhone/iPad layouts; physical camera and upgrade/backup acceptance are still required.

This iPhone candidate has production UI, while the owner's trial continues on the existing beta backend. Server production cutover and App Review submission are separate release steps. The privacy page describes the current beta data handling.
